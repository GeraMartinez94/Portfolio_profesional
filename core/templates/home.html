Pipeline de Streaming con Redpanda (Kafka)
Proyecto personal • Data Engineering
🎯 Objetivo
Aprender los fundamentos de streaming de datos en profundidad: ingesta de eventos en tiempo real, procesamiento con ventanas deslizantes y detección de alertas.
💡 Solución
Armé un pipeline de eventos en tiempo real usando Redpanda (compatible con Kafka) como broker de mensajería, con procesamiento en Python y visualización en vivo de los resultados.
🛠️ Stack Técnico
Python • Redpanda (Kafka) • Streaming de eventos • Procesamiento en tiempo real
Transformación de Datos con dbt + Snowflake + Python
Proyecto personal • Analytics Engineering
🎯 Objetivo
Explorar el stack moderno de transformación de datos, combinando modelos SQL tradicionales de dbt con modelos escritos en Python usando Snowpark.
💡 Solución
Configuré desde cero un entorno en Snowflake (roles, warehouse, permisos) y un proyecto dbt con modelos Python que transforman datos usando DataFrames de Snowpark, en lugar de SQL puro.
🛠️ Stack Técnico
Python • dbt • Snowflake • Snowpark • SQL
Gobernanza de Modelos con MLflow
Proyecto personal • MLOps
🎯 Objetivo
Practicar un flujo MLOps modular para un clasificador de prioridad, cubriendo tracking, versionamiento y registro de modelos.
💡 Solución
Implementé el ciclo de vida del modelo con MLflow (experiment tracking, model registry), con una arquitectura pensada para integrarse con entornos Lakehouse (Snowflake) y orquestadores (dbt/Airflow).
🛠️ Stack Técnico
Python • MLflow • Snowflake • dbt/Airflow (arquitectura de referencia)
